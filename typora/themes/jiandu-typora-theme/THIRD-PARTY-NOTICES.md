## Drake Typora Theme Reference / Drake Typora 主题参考

This Jiandu package was organized and restyled as a new theme pack. The user-provided Drake theme was used as a compatibility reference for the range of Typora elements that benefit from styling, including code blocks, Mermaid diagrams, source mode, sidebars, dialogs, task lists, and print behavior.

本简读主题包为重新组织和重新设计的主题包。用户提供的 Drake 主题用于参考 Typora 中需要兼容的元素范围，包括代码块、Mermaid 图、源码模式、侧栏、对话框、任务列表和打印行为。
