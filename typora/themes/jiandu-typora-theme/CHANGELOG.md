# Changelog / 更新记录

## 0.1.0 — 2026-06-25

- Initial Jiandu Typora theme pack.  
  初版简读 Typora 主题包。
- Seven English-named screen themes.  
  提供七套英文文件名的屏幕主题。
- Shared font presets with a one-line user selector in `jiandu/user-fonts.css`.  
  在 `jiandu/user-fonts.css` 中提供一行式字体选择。
- Shared automatic A4 print/PDF stylesheet.  
  提供统一的自动 A4 打印 / PDF 样式。
- Local print test document with image, table, code, Mermaid, and pagination checks.  
  提供含图片、表格、代码、Mermaid 与分页检查的本地打印测试文档。

## 0.1.1 — 2026-06-25

- Changed the default screen reading font from LXGW WenKai to the formal book-style preset (`--jiandu-font-formal`), which prefers KingHwa OldSong / 京华老宋体.  
  将默认屏幕字体从霞鹜文楷改为正式书刊体预设（`--jiandu-font-formal`），优先使用 KingHwa OldSong / 京华老宋体。
- Changed A4 print body and heading defaults to the same formal book-style fallback chain, while keeping code monospace.  
  A4 打印的正文和标题默认也改为同一套正式书刊体回退链，代码仍保持等宽字体。
- Removed coloured heading-bar and dot-marker decorations to create a more restrained book, thesis, and newspaper layout.  
  移除了标题彩色竖条和圆点装饰，整体改为更克制的书籍、论文、报刊式版面。
- Updated bilingual font documentation.  
  更新中英双语字体说明。
